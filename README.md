# ChatGPT Mobile UI Simulator

A lightweight, standalone ChatGPT UI Simulator designed for recording realistic conversation videos for YouTube (16:9) and YouTube Shorts / TikTok / Reels (9:16).

## Features
- **Dual Aspect Ratios:** Instant toggle between 9:16 (Shorts/Reels) and 16:9 (YouTube widescreen) directly in the Script Panel.
- **Audio Feedback:** Authentic mechanical typing click sound embedded (zero external audio dependencies).
- **Simulated AI Generation:** Realistic dynamic character typing speed, blinking thinking pulse dot, and auto-scrolling chat viewport.
- **Script Customization:** Interactive panel to input custom user questions, AI answers, and pause timings.

## Live Demo
Deployable with zero configuration on Vercel, Netlify, or GitHub Pages.
